## Results

Read a comparison’s Unequal values, Unmatched observations and Return
code.

- [`differences()`](https://ganhualu.github.io/DataComR/reference/differences.md)
  : Unequal values found by a comparison
- [`unmatched_rows()`](https://ganhualu.github.io/DataComR/reference/unmatched_rows.md)
  : Unmatched observations found by a comparison
- [`return_code()`](https://ganhualu.github.io/DataComR/reference/return_code.md)
  : Return code of a comparison
