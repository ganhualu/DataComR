# DataComR: Compare Datasets the Way SAS PROC COMPARE Does

Compares a base dataset with a compare dataset following the semantics
of SAS PROC COMPARE: ID variables, numeric comparison methods, a PROC
COMPARE-style listing and a SYSINFO-style return code. Gives users
familiar with SAS PROC COMPARE a similar tool in R.
